# HOW TO WRITE A VARNAM FOR THE VIDEO MAKER
# Save the real one as  varnanaateetam/videos/<raga>/notation.txt
#
# THIS FILE IS ONLY A SAMPLE OF THE FORMAT. The notes and words below were typed from memory
# and are NOT checked. Replace them with Soujanya's notation.
#
# Top lines: facts about the varnam.
#   notes per beat: 4      how many note places make one beat in first speed
#   order: ...             the order the parts are sung in. "@2" after a name = second speed.
#                          Leave "order" out to sing every part once, top to bottom.
#
# Parts start with a name in square brackets:  [Pallavi]
# Then, for each line shown on screen (half a cycle of Adi tala = 16 note places works well):
#   the notes        S R G M P D N     ,  = hold the note one more place     ;  = hold two places     -  = silence
#                    S' = upper octave     D. = lower octave     | bars are allowed and ignored
#   t: the words in Telugu      one word-piece for each note place, "." where the sound carries on
#   e: the words in English     same rule
# If the count of word-pieces is not the same as the count of note places, they are spread evenly along the line.
